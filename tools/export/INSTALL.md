# 坦克大战 2026 · 安装说明

每个平台的安装包里都附带对应的一节（打包时由 `build.sh` 截取）。

## macOS
坦克大战 2026 · macOS（Apple 芯片：M1 / M2 / M3 / M4）

1. 解压后把“坦克大战 2026.app”拖进“应用程序”文件夹（也可以直接在原地打开）。
2. 第一次打开：在 App 上点右键 →“打开”→ 再点“打开”。
   这个 App 没有经过苹果公证，直接双击会提示“无法验证开发者”，用右键打开一次以后就可以双击了。
   如果提示“已损坏”，在“终端”里执行：xattr -cr "/Applications/坦克大战 2026.app"
3. 第一次启动要几秒钟（解压引擎），之后就快了。

按键：方向键 / WASD 移动，空格 / J 开火；主页按 C 双人合作（2P 用方向键 + Enter），按 E 自己做地图。

## Windows
坦克大战 2026 · Windows（64 位，Windows 10 / 11）

1. 解压后双击 TankBattle.exe。
2. 如果出现“Windows 已保护你的电脑”（SmartScreen），点“更多信息”→“仍要运行”。
   这个程序没有代码签名证书，所以第一次会有这个提示。
3. 第一次启动要几秒钟（解压引擎），之后就快了。

按键：方向键 / WASD 移动，空格 / J 开火；主页按 C 双人合作（2P 用方向键 + Enter），按 E 自己做地图。

## Linux
坦克大战 2026 · Linux（x86_64）

1. 解压：tar -xzf TankBattle-*-linux-x64.tar.gz
2. 运行：./TankBattle
   需要显卡驱动支持 Vulkan 或 OpenGL 3.3。

按键：方向键 / WASD 移动，空格 / J 开火；主页按 C 双人合作（2P 用方向键 + Enter），按 E 自己做地图。

## Web
坦克大战 2026 · 网页版 / iPhone / 安卓（PWA）

【放到网上，手机扫码就能玩】
1. 把 TankBattle 文件夹里的所有文件上传到任意 HTTPS 静态网站（例如七牛云 Kodo + CDN、GitHub Pages、Netlify）。
2. 手机打开网址，点“点击开始”。屏幕两侧有虚拟方向键和开火键；右上角“双人按键”可以在平板上两个人一起玩。
3. iPhone：在 Safari 里点“分享”→“添加到主屏幕”；安卓：浏览器菜单 →“安装应用”。之后像 App 一样全屏打开，第一次加载完后断网也能玩。

【在电脑上试玩】
运行 python3 本地试玩.py，浏览器会自动打开 http://localhost:8080/
（直接双击 index.html 打不开：浏览器不允许本地文件加载游戏引擎）

注意：首次加载约 15 MB（服务器开启 gzip / brotli 时），网页版不能把自制地图保存到文件。

## Android
坦克大战 2026 · Android（arm64，Android 5.0 以上）

1. 把 APK 发到手机上（数据线、微信 / QQ 文件、网盘都可以），点开安装。
2. 如果提示“禁止安装未知来源应用”，按提示在设置里允许这个来源。
3. 这个 APK 用调试证书签名，可以直接安装，但不能上架应用商店。

操作：游戏画面可以直接点（主页、按钮、地图编辑器）；对局中需要键盘或手柄（蓝牙 / OTG）。
手机上更推荐用网页版（PWA），它带触屏虚拟按键。

## iOS
坦克大战 2026 · iPhone / iPad（不签名的 IPA）

苹果不允许直接安装没有签名的 App，需要用你自己的 Apple ID 签名一次：
1. 在电脑上安装 Sideloadly（https://sideloadly.io）或 AltStore（https://altstore.io）。
2. 用数据线连接 iPhone，把这个 .ipa 拖进去，登录你的 Apple ID，等待安装完成。
3. 在 iPhone 的“设置 → 通用 → VPN 与设备管理”里信任你的 Apple ID。
4. 免费 Apple ID 签名的 App 7 天后过期，届时重新安装即可；付费开发者账号可以用 TestFlight 分发。

操作：游戏画面可以直接点；对局中需要蓝牙键盘或手柄。
iPhone 上更推荐用网页版（PWA）：Safari 打开网址 →“添加到主屏幕”，不用签名，带触屏虚拟按键。
