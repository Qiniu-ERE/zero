# 坦克大战 v3.0 · 规划总览

> **状态说明（2026-10-25）**：本文是 v3.0 的规划，写到 v3.0.2 为止。之后的变化（v4.0 自动化测试、本机打包等）以后续版本的文档为准：[v4.0 规划](../v4/PLAN.md)、[更新记录](../../CHANGELOG.md)。

v2.0 把 1985 年的《坦克大战》在 XBuilder 上重做成了 2026 年的样子，但只有一关，只能一个人玩，也只能在 XBuilder 网页里玩。v3.0 要解决四个问题：**内容不够玩、地图只能开发者做、只能一个人玩、只能在电脑网页上玩**。

| 方向 | 内容 | 状态 | 详细文档 |
|---|---|---|---|
| **1. 关卡** | 从 1 关扩展到 8 关，每关的地形和敌军配置都不一样；选关、下一关、全部通关 | ✅ 已实现（[PR #10](https://github.com/Qiniu-ERE/zero/pull/10)） | 本文第一节 |
| **2. 自己做地图** | 玩家用鼠标 / 手指画地图，实时检查，马上试玩 | ✅ 已实现（[PR #14](https://github.com/Qiniu-ERE/zero/pull/14)） | [MAP_EDITOR.md](MAP_EDITOR.md) |
| **3. 双人合作** | 同一台电脑两人各开一辆坦克，一起守基地 | ✅ 已实现（[PR #13](https://github.com/Qiniu-ERE/zero/pull/13)） | [COOP.md](COOP.md) |
| **4. 跨平台** | Windows / macOS / Linux 双击运行；iPhone / 安卓用浏览器（PWA）或 App 运行 | ✅ 打包和发布流程已实现（[PR #15](https://github.com/Qiniu-ERE/zero/pull/15)） | [CROSS_PLATFORM.md](CROSS_PLATFORM.md) |

四个方向互相配合：**8 个关卡**提供基本内容；**自己做地图**让内容不再有上限，编辑器里也锁定了 2P 出生点；**双人合作**可以玩所有关卡和自制地图；**跨平台**让更多人玩到，而且前三项都不依赖网络，打包后在所有平台都能用。

## 一、8 个关卡（已实现）

| 关卡 | 地形 | 敌军 | 开场提示 |
|---|---|---|---|
| 1 钢铁峡谷 | 经典布局，砖墙夹道（v2 原有） | 标准：重型 20%、快速 30%，每 2 秒出兵，场上最多 4 辆 | 消灭 20 辆敌军，守住基地！ |
| 2 水乡迷宫 | 大片水面分割战场，坦克要绕路，子弹能隔河对射 | 标准 | 水网密布：坦克过不了河，子弹可以 |
| 3 丛林伏击 | 草丛遍地 | 快速 60%，每 1.8 秒 | 草丛里埋伏着快速坦克 |
| 4 钢铁堡垒 | 钢墙林立，射击角度少 | 重型 50%，每 2.2 秒 | 钢铁堡垒：重型坦克要打 3 发 |
| 5 砖城巷战 | 密集砖墙街区 | 重型、快速各 30%，每 1.8 秒 | 巷战：打穿砖墙，开出一条路 |
| 6 闪电突袭 | 开阔地，几乎无处躲 | 快速 70%，每 1.2 秒，场上最多 5 辆 | 闪电突袭：敌军来得更快 |
| 7 双子要塞 | 左右两座砖堡，中间一道水渠 | 快速 50%、重型 30%，每 1.5 秒，场上最多 5 辆 | 双子要塞：小心两侧的交叉火力 |
| 8 最终决战 | 水、草、钢都有，基地两侧有钢墙 | 重型、快速各 45%，每 1.3 秒，场上最多 5 辆 | 最终决战：守住最后的防线！ |

![8 个关卡和全部通关画面（spx run 实际截图）](stages/stages.png)

- **流程**：胜利后按「下一关」，得分带到下一关；第 8 关胜利显示「全部通关！」；战败后重打本关，得分回到进关时的分数。主页按 1~8 可以直接选关。
- **关卡检查**：`python3 tools/levels/check.py` 检查每张地图的出生点、基地和连通性。编辑器里的实时检查用同一套规则。
- **代码**：地图在 `main.spx` 的 `levelMap()`，敌军配置在 `stageTune()`。没有给任何精灵加字段，不影响解释器的方法表上限。

## 二、自己做地图（已实现）

| 编辑中 | 地图有问题：出生点标红 | 试玩胜利：继续编辑 |
|---|---|---|
| ![](editor/editor-zh.png) | ![](editor/editor-bad-zh.png) | ![](editor/result-edit-zh.png) |

- 主页按 E 进入。鼠标点击或拖动绘制（触屏会当作鼠标），1~5 选工具，M 对称绘制，R 随机起点，K 从现有关卡复制，C 清空，Enter 试玩，P 双人试玩，S 保存。
- 出生点和基地是锁定格；每画一笔都检查一次，不合格时标红并说明原因，合格才能试玩。
- 保存：PC 版存到 `os.UserConfigDir()/TankBattle/maps.txt`，下次自动载入；网页版没有文件系统，地图只保留到关闭页面。
- 详见 [MAP_EDITOR.md](MAP_EDITOR.md) 第七节（实现结果和验证记录）。

## 三、双人合作（已实现）

| 主页（按 C） | 双人对局 |
|---|---|
| ![](coop/home.png) | ![](coop/coop-zh.png) |

- 1P：WASD + J；2P：方向键 + Enter。2P 是青绿色坦克，在基地右边出生。
- 每人 3 条命，基地被毁或两人都没命才算输；复活每局一次，两人各加 1 条命；没有友军伤害；双人时敌人来得稍快。
- 2P 是 `Player` 的克隆，没有新增精灵类型和字段；敌人子弹按“离哪辆活着的坦克更近”判断打中了谁。
- 测试中发现：一人中弹时广播的消息会打断另一人正在等待的重生，已改成在每帧里倒计时（见 [架构文档 9.3](../ARCHITECTURE.md)）。
- 详见 [COOP.md](COOP.md) 第六节。

## 四、跨平台（已实现，已发布 [v3.0.0](https://github.com/Qiniu-ERE/zero/releases/tag/v3.0.0)）

| 平台 | 安装包 | 验证 |
|---|---|---|
| Windows / macOS / Linux | `spx buildlauncher` 单文件程序（macOS 包成 `.app`） | v3.0.0 时在 CI 上启动并截图；v3.0.2 起本机启动测试（Linux 在虚拟机里） |
| 网页版（iPhone / 安卓 / 浏览器） | `spx exportweb` + 外壳页面（PWA、触屏虚拟按键） | 本机模拟 iPhone 测试 |
| Android | APK（调试证书签名，触屏模式） | 检查了包内容，**还没在真机上运行** |
| iOS | 不签名的 IPA（触屏模式） | 检查了包内容，**还没在真机上运行** |

v3.0.0、v3.0.1 是推送 `v*` 标签后由 GitHub Actions 自动打包并创建 Release 的。组织的 Actions 额度用完后，**v3.0.2 起改为本机打包**（现在用 `tools/export/build_local.sh` + `release_local.sh`），Actions 只能手动触发。详见 [CROSS_PLATFORM.md](CROSS_PLATFORM.md) 第七节。
