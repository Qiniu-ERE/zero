# 坦克大战 v5.0 · 规划总览：商业化落地探索

> **本版先只做文档**：评估怎么把游戏放到主流平台上卖。**聚焦五个平台：Steam（PC / Steam Deck）、Xbox（PC 和主机）、PlayStation、Apple App Store、Google Play**。文档合入后，再按第五节的拆分逐个 PR 实施。
>
> 依据分三类，文中都已标明：
> - **代码**：读本仓库 `main`（v3.0.2，`fc7e64e`）和 spx 源码（`c3c0da5`）确认的现状。
> - **公开资料**：2026-10-25 查阅的平台文档和公开报道，来源列在 [PLATFORMS.md](PLATFORMS.md) 末尾。平台规则经常变，**提交前要以官方文档重新核对**。
> - **推测**：没有条件验证的判断，包括所有价格和销量。

v2.0 做出了现代画风和 4 个**模拟**广告位，v3.0 做出了 8 个关卡、自己做地图、本地双人合作和六个平台的安装包，v4.0 补上了自动化测试。到现在为止游戏**没有在任何平台上架**：安装包只放在私有仓库的 Releases 里，广告是游戏里画出来的。

## 一、结论先说

| 平台 | 能不能做 | 一句话 |
|---|---|---|
| **Steam（Windows / macOS / Linux / Steam Deck）** | ✅ **首选** | 三个桌面包都已经能打，花 $100 就能上架；差的是**手柄支持**、商店版和改名 |
| **Xbox · PC（Microsoft Store）** | ✅ 可以 | 个人开发者注册免费（2025-09 起），Windows 包用 MSIX 封装后提交；和 Steam 共用大部分准备工作 |
| **Apple App Store（iPhone / iPad）** | ⚠️ 可以，有前提 | 已经能出不签名的 IPA；要 Apple 开发者账号（$99 / 年）、用 Xcode 26 / iOS 26 SDK 重新编译签名。**中国区要版号，不上**；只上其他地区 |
| **Google Play** | ⚠️ 要先升级引擎 | 新应用必须交 AAB、目标 API 36（2026-08-31 起），64 位原生库要支持 16 KB 页（更新包从 2027-02-01 起强制）。spx 现在的 Android 模板是 Godot 4.4.1、只能出 APK、目标 API 34，**做不到**。要等 spx 升级 Godot 或者自己改 |
| **Xbox · 主机（Series X\|S）** | ❌ 近期不做 | 需要公司主体加入 ID@Xbox、Godot 的主机移植（W4 Games 等第三方，收费）；更根本的是 **spx 的游戏逻辑跑在 Go 写的解释器里，Go 不支持主机系统** |
| **PlayStation 5** | ❌ 近期不做 | 同上；PlayStation Partners 要求公司主体（欧洲可以个体户） |

**主机要做，只能把游戏逻辑从 spx 改写成 GDScript（或 C#）**，再用第三方主机移植模板。约 2700 行游戏代码要重写，测试也要重来（v4 的测试框架基于 spx）。这是 v6 级别的决定，**Steam 卖得好再考虑**（见 TECH.md 第五节）。

**商业模式**：这五个平台的玩家习惯买断制，而且买断**不需要接任何 SDK**（我们最大的技术卡点就是游戏脚本调不到外部 SDK）。所以 v5 的商店版都是**付费下载、没有广告**，模拟广告位全部去掉；Steam 再出一个免费试玩版拉愿望单。详见 [MONETIZATION.md](MONETIZATION.md)。

## 二、现状：离“能上架”还差什么（代码）

| 项目 | 现在 | 上架需要 |
|---|---|---|
| **手柄** | **完全不支持**。spx 没有给游戏脚本提供手柄接口（源码里只有网页版引擎的 JS 库里有手柄代码），游戏只认键盘、鼠标、单指触屏 | Steam Deck 认证、Xbox、PlayStation 都要求手柄能玩全部内容，按键提示要显示手柄图标 |
| **模拟广告** | 主页横幅（“七牛云 · 本广告位招商中”）、右侧原生广告卡、复活和金币 ×2 的模拟激励视频 | **付费游戏里不能有假广告**。商店版全部去掉：复活改成每局一次免费复活（或金币复活），金币 ×2 去掉 |
| **名字** | 英文标题就是 `BATTLE CITY`（`strings.py`），这是原作（Namco 1985）的名字 | 商店页、开发者账号里的应用名、商标都绑定名字，**上架前必须改名**（见 PLATFORMS.md 第八节） |
| **存档** | 只有 PC 版能存一张自制地图；金币、最高分不保存 | 至少保存最高分、通关进度、设置、金币和外观 |
| **桌面包** | Windows / macOS / Linux 单文件程序；第一次运行把引擎解压到用户缓存目录 | Steam 直接用；Windows 包可能被杀毒软件误报（自解压），要观察 |
| **Android** | 调试证书签名的 APK，Godot 4.4.1 模板，目标 API 34，NDK r23c 编译的 Go 库 | AAB、正式签名、目标 API 36、16 KB 页对齐 |
| **iOS** | 不签名的 IPA，CI 上用 Xcode 编译 | Xcode 26 / iOS 26 SDK 编译、开发者证书签名、隐私清单 |
| **打包环境** | GitHub Actions 额度用完（2026-10-25），只能本机打包；本机没有 Xcode，磁盘只剩约 9 GB | iOS 需要一台装 Xcode 26 的 Mac（Xcode 本身要几十 GB） |

## 三、范围

**做**：

- 文档：本文、[PLATFORMS.md](PLATFORMS.md)、[MONETIZATION.md](MONETIZATION.md)、[TECH.md](TECH.md)（本 PR）。
- 商店版：改名、去掉模拟广告、存档、手柄。
- 上架 Steam（含试玩版），同时提交 Microsoft Store（PC）。
- Apple App Store（中国区以外）。
- Google Play：跟进 spx 的引擎升级，条件具备再做。

**不做**：

- 主机移植（只做评估，见 TECH.md 第五节）。
- 广告、内购、抽卡、卖数值。
- 中国大陆的商店和小游戏（都需要版号或另一套资质；之前的评估见 [v3.0 微信小游戏评估](../v3/WECHAT_MINIGAME.md)）。
- 联网对战（Steam 的 Remote Play Together 可以让本地双人合作直接在线玩，不需要我们写网络代码）。

## 四、为什么先做 Steam

- **包已经有了**：三个桌面平台的单文件程序 v3.0 起就能打，Linux 包在 Steam Deck 上原生运行（Steam Deck 是 x86_64 Linux）。
- **门槛最低**：个人可以注册，每款游戏一次性 $100，销售额达到 $1000 后返还（公开资料）。
- **卖点契合**：本地双人合作 + Remote Play Together、地图编辑器，在 Steam 上都是常见的标签。
- **验证成本低**：先开“即将推出”页面和免费试玩版，用**愿望单数量**判断值不值得继续投入，不用先花大钱。
- **手柄是共同前提**：为 Steam Deck 做的手柄支持，以后 Xbox、PlayStation、iPad 外接手柄都能用。
