# 坦克大战 v5.0 · 渠道与合规

> [v5.0 规划](PLAN.md)的第二个方向。**公开资料**都是 2026-10-25 查阅的，大部分来自第三方文章而不是平台官方文档，文末列了来源。**平台规则经常变，提交前一律以官方文档为准重新核对。** 本文不是法律意见。

## 一、渠道一览

| 渠道 | 我们已有的包 | 变现 | 门槛（公开资料） | 费用 | 适合度 |
|---|---|---|---|---|---|
| **海外 H5 门户**（CrazyGames 等） | 网页版 `web.zip` | 门户 SDK 的激励视频 / 插屏，按月分成 | 不需要版号；要接门户 SDK、过 QA；首次下载 ≤ 50 MB（进手机首页 ≤ 20 MB）；**必须原创、和已有游戏明显不同** | 免费 | ⭐⭐⭐ **首选**：成本最低，最快拿到真实数据 |
| **自有网页版** | 网页版 | 不靠它赚钱：演示、年会版投放、七牛云推广位 | 国内访问要用**已 ICP 备案**的域名 | 七牛云 Kodo + CDN 流量费、域名 | ⭐⭐⭐ 必做，成本低 |
| **微信小游戏** | 没有，要用 `spx exportminigame` 新做（[v3.0 评估](../v3/WECHAT_MINIGAME.md)） | 流量主广告（激励视频、Banner） | 不开内购可以不要版号；要软著或电子版权认证、自查报告、**ICP 备案**；开广告要开通流量主 | 软著 / 备案的时间成本 | ⭐⭐ 国内主渠道，但技术卡点多（真机性能、广告桥） |
| **抖音小游戏** | 同上 | 广告 | 和微信类似：个人只能做广告变现，要软著（接受电子版权认证）和自审报告；**同一份软著只能对应一款小游戏**，游戏名要和软著名称一致 | 同上 | ⭐ 放在微信之后 |
| **Google Play** | APK（调试签名） | AdMob、Play 结算（去广告） | 个人账号的新应用要先 **12 人连续 14 天封闭测试**才能申请上架；要正式签名的 AAB | 一次性 $25 | ⭐⭐ 海外 App 的主渠道；AdMob 需要 spx 支持 Android 插件（[TECH.md](TECH.md)） |
| **国内安卓商店**（华为、小米、OPPO、vivo 等） | APK | 广告联盟 | 游戏类基本都要版号；App 要 ICP 备案；软著 | — | ✗ 没有版号走不通 |
| **App Store** | 不签名的 IPA | — | 中国区：所有 App 要 ICP 备案，**游戏要版号**，没有免费游戏的例外；其他地区要 Apple 开发者账号 | $99 / 年 | ✗ 中国区走不通；海外区优先级低 |
| **Steam** | Windows / macOS / Linux 单文件程序 | 买断 | Steam Direct，每款游戏一次性费用（收入达到一定额度后返还） | $100 / 款 | ⭐ 体量小，买断收入有限 |
| **itch.io** | 桌面版、网页版 | 买断 / 自愿付费 | 几乎没有门槛，分成比例由开发者自己设 | 免费 | ⭐ 适合放“支持一下作者”的版本，顺便收集反馈 |

### 推荐顺序

1. **自有网页版 + CrazyGames**（P2）：不需要任何国内资质，一周内能上线，用真实玩家数据回答“值不值得继续”。
2. **软著、ICP 备案并行申请**：周期长（软著常见说法是一个月以上），在 P2 期间就开始办，否则到 P3 会卡住。**先定商业版名称再申请软著**，因为平台要求游戏名和软著名称一致（见第三节）。
3. **微信小游戏**（P3）：数据达标后再做。
4. **Google Play**（P4）：先解决 Android 广告插件，再找 12 个以上的测试者跑 14 天。
5. Steam / itch.io：有余力再上，不影响主线。

## 二、国内资质清单

| 资质 | 用在哪里 | 谁能办 | 说明（公开资料，需核实） |
|---|---|---|---|
| **计算机软件著作权（软著）** | 微信 / 抖音小游戏、国内商店 | 个人或企业 | 名称、版本号在申请材料、平台登记和游戏里要一致；2026 年的文章提到审核趋严，**纯 AI 生成的代码可能被拒** |
| 电子版权认证 | 抖音、QQ 小游戏等（微信是否接受需核实） | 同上 | 比软著快，常见做法是先用它上线跑数据，软著并行办 |
| **ICP 备案** | 小游戏、App、国内网站（自有网页版的域名） | 个人或企业 | 2023 年 9 月起 App 和小程序都要备案；个人主体办游戏类备案可能被拒 |
| 游戏自审自查报告 | 小游戏 | — | 平台提供模板 |
| **网络游戏版号** | 内购、国内商店、App Store 中国区 | 只能由出版单位申报 | 周期长、成本高，**v5 不申请**，所以国内只做广告变现 |
| 实名认证与防沉迷 | 有版号的网络游戏 | — | 小游戏平台对未成年人有统一的限制；不做内购时由平台处理的部分要以平台规则为准 |

**主体选个人还是企业**：个人主体只能做广告变现（接不了内购），这和 v5 的“国内不做内购”一致；但年会版、品牌版等 B2B 业务要开发票、签合同，需要企业或个体工商户主体。建议 P2 期间决定。

## 三、知识产权：商业化前必须处理

游戏是 1985 年 FC《坦克大战》（Namco，英文名 *Battle City*）的复刻重铸版。比赛作品这样写没有问题，商业化之后风险完全不同。

| 项目 | 现状（代码） | 风险 | 处理 |
|---|---|---|---|
| **英文标题** | `strings.py` 里英文标题就是 `BATTLE CITY` | *Battle City* 是原作名称，商用可能侵犯商标 | 商业版换一个新名字（中英文都换），中文“坦克大战”是通用叫法，但为了和软著名称、平台登记一致，也建议起一个独有的名字 |
| README 徽章 | “remake of Battle City 1985” | 仓库里可以保留（说明来历）；商店页面和宣传素材里不要用原作名称和截图 | 商店描述写“经典坦克玩法”，不写原作名 |
| 玩法 | 守老鹰、打砖墙、20 辆敌人一关 | 玩法本身一般不受著作权保护，但门户要求“和已有游戏明显不同”，审核可能因为太像而拒绝 | 突出差异：现代画风、自己做地图、双人合作、8 张原创地图；P2 再评估是否把“老鹰”换成别的基地造型 |
| 美术 | 全部原创，由 `build.py` 生成；老鹰图标是自己画的路径 | 低 | 保留生成脚本和提交记录，作为原创证明 |
| 音效 | 全部程序合成，没有用原版音乐或采样（README 版权说明） | 低 | 同上 |
| 字体 | Noto Sans SC，SIL OFL 1.1，构建时转成路径 | 低，OFL 允许商用和嵌入 | 在“关于”里注明 |
| 引擎和工具 | spx（Apache-2.0）、Godot（MIT） | 低 | 在“关于”或安装包里附上许可证文本 |
| 关卡 | 8 张地图是自己设计的（`levels/check.py` 校验） | 低 | — |

**改名是 P2 的第一件事**：软著、平台账号、域名、商店页面都绑定名称，先改名再申请，后面就不用再改。

## 四、七牛云：自有网页版的托管

仓库是组织的免费私有仓库，没有 GitHub Pages（[CROSS_PLATFORM.md](../v3/CROSS_PLATFORM.md)），网页版需要自己找地方放。七牛云的 Kodo（对象存储）+ CDN 正好合适：

- `web.zip` 解压后上传到 Kodo，绑定 CDN 加速域名；国内访问的域名**必须已 ICP 备案**，海外访问可以用海外加速。
- 要设置正确的 MIME 类型（`.wasm` 为 `application/wasm`，和 `play-local.py` 里一样）和压缩（`.br` / gzip）。我们用的是单线程 Web 引擎（`setup web --mode normal`，见 [v3.0 小游戏评估 2.2](../v3/WECHAT_MINIGAME.md#22-单线程源码)），不需要 `SharedArrayBuffer`，所以**不用配** COOP / COEP 响应头，也就不影响在门户的 iframe 里运行。
- PWA 的 Service Worker 缓存名带版本号（`tools/export/web/sw.js`），发布新版本后旧缓存会自动清掉，CDN 刷新只需要刷 `index.html` 和 `sw.js`。
- 年会版可以用子目录或子域名，一个客户一套，互不影响。

上传脚本（`tools/export/deploy_qiniu.sh`，用七牛的 `qshell`）放在 P2 实现。
